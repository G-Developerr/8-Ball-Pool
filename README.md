# 🎱 8-Ball Pool Game

A browser-based 8-ball pool game built with HTML5 Canvas and JavaScript.

## 🚀 Live Demo
[Play Now] (https://g-developerr.github.io/8-Ball-Pool/)

## 🎮 Game Modes
- 👥 **2 Player** — Play against a friend on the same device
- 🤖 **vs AI** — Challenge the computer

## 🕹️ How to Play
- Drag the mouse from the cue ball to aim
- Release to shoot
- Pot all your balls (solids or stripes) then sink the 8-ball to win
- Don't pot the 8-ball early or you lose!

## ✨ Features
- Realistic ball physics
- 2 Player local multiplayer
- AI opponent
- Score tracking
- Reset game button

## 🛠️ Tech Stack
- HTML5 Canvas
- Vanilla JavaScript
- CSS3
